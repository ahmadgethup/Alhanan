# مدرسة حنان | متابعة الطلاب

مشروع Next.js مستقل مبني على واجهة التجربة، وفيه تقييم الطلاب ومعاينة تقارير A4 وتنزيلها بصيغة PDF. النسخة الحالية تعرض بيانات وهمية وتحفظ تغييرات التجربة في المتصفح.

## التشغيل محلياً

باستخدام Node.js 22 أو 24:

```bash
npm ci
npm run dev
```

افتح http://localhost:3000. للتحقق من بناء المشروع شغّل `npm run build`.

## الخطوة القادمة

أنشئ مشروع تطوير في Supabase. عند الربط، انسخ `.env.example` إلى `.env.local` وأضف رابط المشروع والمفتاح القابل للنشر. لا تستخدم مفتاحاً سرياً في متغير يبدأ بـ `NEXT_PUBLIC_`.

نبدأ بمدرّس تجريبي وشعبة واحدة، ونختبر تسجيل الدخول وصلاحيات المدرّس والإدارة، ثم حفظ تقييم أسبوعي وعرضه وتنزيله. تُستخدم بيانات وهمية خلال الاختبار.

## عرض أسماء الطلاب من Supabase

في مجلد المشروع على جهازك، أبقِ رابط Supabase في `.env.local` وأضف
`SUPABASE_SECRET_KEY` من **Settings → API Keys → Secret keys**.
احتفظ بالمفتاح في هذا الملف المحلي، دون بادئة `NEXT_PUBLIC_`.

شغّل `npm ci` ثم `npm run dev` وافتح http://localhost:3000/roster.
اختر الصف والشعبة. القائمة تقرأ من جدول `public.hanan_students`.
مسار قراءة الأسماء يعمل في وضع التطوير المحلي، وتقييمات الواجهة الأصلية تجريبية.

## شاشة أنا معلّم

اضغط «أنا معلم» من الصفحة الرئيسية أو افتح http://localhost:3000/teacher.
اختر المادة والصف والشعبة وتاريخ نهاية الأسبوع. تظهر أسماء الشعبة من
Supabase، وتُحفظ التقييمات على المتصفح حسب الطالب والمادة وتاريخ الأسبوع.
